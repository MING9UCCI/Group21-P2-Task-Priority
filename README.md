# Group21 — 오늘 할 일 우선순위 추천 시스템

대학생의 여러 할 일을 긴급도, 중요도, 남은 작업량에 따라 비교하여 오늘 먼저 할 일 **최대 3개와 추천 이유**를 제공합니다. 알고리즘 및 컴퓨터적 사고 팀 프로젝트의 Python 프로토타입입니다.

## 실행 방법

1. `Group21_P2.ipynb`를 다운로드하여 Google Colab 또는 Jupyter Notebook에서 엽니다.
2. 모든 셀을 순서대로 실행합니다. 기본값은 더미 데이터 모드이며, 별도의 설치나 외부 데이터는 필요하지 않습니다.
3. 직접 입력하려면 첫 코드 셀의 `USE_DUMMY_DATA`를 `False`로 변경합니다.

## 구현 구조

| 단계 | 함수 | 역할 |
|---|---|---|
| C1 | `collect_tasks()` | 입력 검증, 완료 작업 제외 |
| C2 | `add_urgency_scores(tasks)` | 마감까지의 남은 일수를 긴급도 점수로 변환 |
| C3 | `add_remaining_work(tasks)` | 예상 시간 × 미완료 비율로 남은 작업량 계산 |
| C4 | `calculate_priority_scores(tasks)` | 세 항목 점수 합산(최대 15점) |
| C5 | `recommend_top3(tasks)` | 점수 정렬, 동점 처리, 상위 최대 3개와 추천 이유 반환 |

동점일 때에는 마감이 가까운 일, 중요도가 높은 일, 입력 순서 순으로 처리합니다.

## 실행 예시 및 테스트

더미 데이터 6개 중 완료된 항목 1개를 제외한 결과:

| 순위 | 할 일 | 점수 |
|---|---|---:|
| 1 | 과제 제출 | 14 |
| 2 | 보고서 작성 | 13 |
| 3 | 발표 준비 | 13 |

정상 처리, 완료 항목 제외, 동점, 추천 대상 0~2개, 점수 경계값, 잘못된 입력 및 빈 목록을 검증하는 테스트를 포함합니다.
